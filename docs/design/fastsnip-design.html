Text mode

Live Text demo

Text mode doesn't copy anything by itself. It turns the text on screen into real, selectable text in place, like Live Text on iPhone, and you choose what to copy. Try it: drag a box over the page below, or press Whole screen. Then drag across words, double-click a word, triple-click a line, or press CtrlA. Copy with the bar or CtrlC.

Edge cases

When something goes wrong

Shortcut already in use

Win + Shift + R is taken by Xbox Game Bar. Pick another or turn it off in Game Bar.

Choose another
Windows still opens its own tool on PrtSc

Turn off "Use the Print screen key to open screen capture" in Windows Settings, then press PrtSc again.

Open Windows Settings
No text found

Shown inside the selection for 1.5 seconds. Try a bigger area, or zoom the page and try again.

Save folder is missing

Pictures\Screenshots no longer exists. The image is on your clipboard. Choose a folder to keep saving.

Choose folderRecreate it
Text Recognizer not ready

Windows is still downloading the model. FastSnip uses Windows.Media.Ocr until it's ready, then switches automatically.

Exclusive full screen game

The frame is grabbed first, so the screenshot always works. The overlay may make the game minimize. Use Snip full screen or the recording shortcut to skip the overlay.
